# UrlShortener

## Была выбрана база данных SQLite по следующим причинам:
- **Простота установки и настройки**: SQLite не требует сложной установки и конфигурации, что делает процесс начала работы быстрым и удобным.
- **Легковесность**: SQLite представляет собой компактную и легковесную базу данных, что особенно удобно для тестирования, когда не требуется масштабирование или высокая производительность.
- **Подходит для локального использования**: SQLite хранится в одном файле, что удобно для локальной разработки и тестирования, не требуя отдельного сервера баз данных.
- **Хорошая поддержка в среде .NET**: Entity Framework Core хорошо поддерживает SQLite, что упрощает работу с базой данных в приложениях на платформе .NET.

## Запуск проекта:
`dotnet build --project src/UrlShortener.Web`

`dotnet run --project src/UrlShortener.Web`
